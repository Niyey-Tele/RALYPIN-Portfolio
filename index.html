Self-Driving Obstacle Avoidance Tank Robot

August 2026
Arduino HC-SR04 SG-90 L298N FSM

A fully autonomous self-driving tank robot built on Arduino with ultrasonic sensing, servo scanning and intelligent path decision-making. It operates entirely independently without Bluetooth, WiFi or remote control, using a differential tank-wheel drive structure.

Key Features:
  • Finite State Machine (FSM) control: IDLE → EVADE → SCAN → DECIDE workflow
  • 180° environment scanning via HC-SR04 sensor + SG90 servo scanner
  • Dual isolated power system eliminates motor noise interference
  • Parallel motor wiring for consistent wheel speed and precise tank spin
  • Real-time serial monitoring with distance, angle and decision output
What I Learned:
  • Embedded FSM programming for stable, jitter-free autonomous behavior
  • Hardware power isolation principles and noise suppression techniques
  • Step-by-step hardware troubleshooting and component fault diagnosis
  • Full autonomous decision pipeline from sensor input to motion output

Hardware / IoT / Wireless

WiFi Remote Control Tank

August 2026 | Self-Study Project
EPS-32-S3 Arduino WiFIAP Web Sever UART

A WiFi-controlled tank robot built on an ESP32-S3 + Arduino dual-controller architecture. The ESP32-S3 creates its own WiFi hotspot and hosts a mobile web control interface, allowing a smartphone to drive the tank through a browser. Commands are forwarded to the Arduino via UART serial communication, which drives the L298N motor controller and onboard headlights.

Key Features:
  • ESP32-S3 WiFi AP mode — phone connects directly, no router needed
  • Responsive web UI with press-and-hold controls: hold to move, release to auto-stop
  • 6 commands: forward, backward, left turn, right turn, stop, headlight on/off
  • UART serial link (ESP32-S3 TX → Arduino RX) with shared-ground signal reference
  • L298N dual H-bridge motor driver on tank chassis
  • Optional connection-loss timeout safety stop
  • Highly scalable — can add auto obstacle avoidance, sun-tracking self-charging, PWM speed control, Bluetooth backup, or long-distance network control

Hardware / IoT / Sensors / Web

ESP32-S3 Environment Monitor

August 2026 | Self-Study Project
EPS-32-S3 DHT11 LittleFS REST API HTML/CSS/JS

A real-time environmental monitoring system built on ESP32-S3, measuring ambient temperature, humidity, and soil moisture. The ESP32-S3 connects to WiFi and hosts a responsive dark-themed web dashboard that auto-refreshes every 5 seconds. Sensor data is exposed through a REST API returning JSON, and the web interface is stored on the onboard LittleFS flash filesystem — demonstrating a complete embedded full-stack architecture where C++ runs on the microcontroller and HTML/JavaScript runs in the browser.

Key Features:
  • DHT11 digital sensor for temperature (°C) and relative humidity (%)
  • Capacitive soil moisture sensor via ADC1 analog input (GPIO 10), calibrated to 0–100%
  • ESP32-S3 WiFi station mode — connects to home WiFi, accessible from any device on the network
  • Built-in web server on port 80 with two routes: "/" serves dashboard, "/data" returns JSON
  • LittleFS flash filesystem stores index.html separately from firmware — UI updates without recompiling C++
  • REST API endpoint returns JSON: {"temperature": 28.5, "humidity": 65.0, "soil_moisture": 45.0}
  • JavaScript fetch() auto-refreshes sensor readings every 5 seconds without page reload
  • Responsive dark-mode card UI with cyan accent, optimized for both phone and desktop browsers
  • Manual "Refresh Now" button for on-demand readings alongside auto-refresh
  • NaN-safe sensor reading — returns 0.0 instead of corrupt values when sensor is disconnected
  • PlatformIO professional project structure: src/ (C++ firmware), data/ (web assets), platformio.ini (build config)
  • Highly scalable — can add data logging, MQTT integration, OTA updates, history charts, or Home Assistant integration
