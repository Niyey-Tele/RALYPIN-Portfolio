# RA LYPIN — Personal Portfolio Website

My personal portfolio website built from scratch with HTML, CSS, and JavaScript.
Showcasing my projects, engineering training, and skills as a Communication
Engineering student.

## 🌐 Live Website

https://niyey-tele.github.io/RALYPIN-Portfolio/

## 🛠 Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties (variables), responsive grid, flexbox, animations
- **Vanilla JavaScript** — mobile menu, smooth scroll, typewriter effect, scroll reveal
- **GitHub Pages** — hosting & deployment

## ✨ Features

- Fully responsive design (mobile, tablet, desktop)
- Sticky navigation with active section highlighting
- Smooth scrolling and scroll-reveal animations
- Typewriter hero effect
- Project gallery with hover interactions
- Engineering Training & Practice section
- Back-to-top button
- Mobile hamburger menu

## 📁 Project Structure

├── index.html          # Main page
├── styles.css          # All styles (CSS variables + responsive)
├── images/             # Project photos, profile, certificates
├── ImagePract/         # Engineering training photos
├── PDF/                # Resume, reports
└── README.md

## How to Run Locally

1. Download or clone the entire repository (not just index.html)
2. Make sure all folders are kept together:
   - `index.html` and `styles.css` must be in the same folder
   - `images/`, `ImagePract/`, and `PDF/` folders must be present
3. Use any tools as you always use to run a live sever

> Note: If you only open index.html without styles.css, the page will show
> as plain text with no styling. If image folders are missing, photos will
> appear as broken icons.
